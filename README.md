# Employee Management System

## Project Description
The Employee Management System is a Java desktop application designed to manage employee information efficiently. It uses Java Swing for the graphical user interface and JDBC to connect with a MySQL database.

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- Apache NetBeans IDE
- XAMPP / phpMyAdmin

## Features
- Add employee records
- View employee records
- Update employee information
- Delete employee records
- Clear the form
- Store employee information in MySQL

## Database Details
- Database Name: akhil
- Database: MySQL
- SQL File: database.sql

## Installation and Execution
1. Install Java and Apache NetBeans.
2. Start MySQL using XAMPP.
3. Import database.sql using phpMyAdmin.
4. Open the project in NetBeans.
5. Check the database connection settings.
6. Run the project.

## Database Setup
1. Open http://localhost/phpmyadmin
2. Import database.sql.
3. Verify the database tables.
4. Ensure the JDBC connection settings are correct.
